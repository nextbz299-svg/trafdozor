# trafdozor
ТрафДозор — облачный сервис анализа трафика и защиты сайтов от ботов, парсеров и подозрительной автоматизированной активности. Готовится новый модуль Ad Traffic Protection для мониторинга качества рекламного трафика, выявления ботов и подозрительных переходов из Telegram Ads, Google Ads, VK Ads и Яндекс Директ.
